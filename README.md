# context-cli (`ctx`)

Интерактивная консольная утилита для подсчета токенов в проекте и сборки исходного кода в один текстовый файл для отправки в LLM (ChatGPT, Claude, Gemini и др.).

## Возможности

*   **Подсчет токенов:** оценивает объем кода с помощью `tiktoken` (`o200k_base`), помогая заранее подобрать модель с нужным контекстным окном.
*   **Поддержка `.gitignore`:** автоматически игнорирует файлы и папки из `.gitignore`, а также бинарные файлы и служебные директории (`.git`, `node_modules`, `.venv` и т. д.).
*   **Двухэтапный интерактивный выбор:**
    1. Выбор нужных директорий целиком с отображением веса каждой папки в токенах.
    2. Опциональное точечное уточнение списка отдельных файлов.
*   **Удобный формат вывода:** сохраняет выбранные файлы в единый текстовый файл, оборачивая каждый исходник в теги `<file path="...">...</file>` для четкого разделения границ моделью.

## Требования

*   Python 3.10 или выше.

## Установка

### Через `pipx` или `uv` (рекомендуется)
Изолированная установка — команда `ctx` станет доступна глобально из любой папки:

```bash
# Через pipx
pipx install git+https://github.com/Homthor/context-cli.git

# Или через uv
uv tool install git+https://github.com/Homthor/context-cli.git
